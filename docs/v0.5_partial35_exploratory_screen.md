# V0.5 PARTIAL35 exploratory screening workflow

This workflow screens the exact 35-candidate subset that passed the frozen `competition_v1` MMFF convergence gate. It is explicitly a `PARTIAL_EXPLORATORY_SCREENING` package and must never be represented as a complete Top40 screen.

## Scientific boundaries

- Parent conformer protocol: `tfr1_top40_sdfgen_competition_v1_b3derived`
- Parent protocol SHA-256: `f79031dda94e148b851774b33082117ffde70f12b4cbf70b7f90a3266226a4a7`
- Included candidates: 35, exactly as frozen in `specs/partial35_exploratory_package_v05.json`
- Excluded candidates: A8, B1, D3, D7, D10
- Exclusion reason: `CONFORMER_GENERATION_QC_FAIL`
- Screening status: `CONFORMER_GENERATION_QC_FAIL_NOT_DOCKED`
- Formal conformers: `conf01`, `conf02`, `conf03`, for 105 total SDF/PDBQT inputs
- The five excluded candidates were not evaluated by docking; the exclusion is not evidence of weak binding or biological inferiority.

All contact, eligibility, representative, receptor, box, ligand-preparation, Vina-score, and completion/resume semantics remain those frozen in V0.4/V0.5-B. AutoDock Vina values are predicted docking scores, not experimental binding free energies.

The active competition exploratory docking protocol is `tfr1_partial35_competition_exploratory_ex16_v05`, raw-byte SHA-256 `c94218bce29ff52f8b052ba04f7a6ef5701440ce31c6e76d2d727be7630b37ee`. It uses AutoDock Vina 1.2.7 with `exhaustiveness=16`, `num_modes=20`, `energy_range=5`, `seed=1701`, `cpu=8`, and process concurrency 1. The earlier `exhaustiveness=32` attempts under `partial35_exploratory_v05/batch_run` are historical runtime records only and must not enter this protocol's analysis or ranking.

## Output isolation

The conformer package is written only to:

`<DATA_ROOT>/standardized_ligands/partial_packages/competition_v1_partial35_mmff_qc_pass`

The complete-Top40 path `<DATA_ROOT>/standardized_ligands/tfr1_top40_sdfgen_competition_v1_b3derived` remains reserved.

The PDBQT/inventory package is written only to:

`<DATA_ROOT>/docking_test/partial35_exploratory_v05/inputs`

The ex16 batch output used below is:

`<DATA_ROOT>/docking_test/partial35_exploratory_ex16_v05/batch_run`

Every publisher is exclusive-create and refuses an existing destination. There is no `--force` mode.

## Gate A: conformer generation

Run only after the feature branch is committed, pushed, and clean so the package records the exact generator commit:

```powershell
python scripts/generate_partial35_conformers.py `
  --contract specs/partial35_exploratory_package_v05.json `
  --protocol specs/competition_conformer_protocol_v1.json `
  --data-root <DATA_ROOT>
```

Generation is sequential by candidate and calls the existing frozen `generate_candidate_conformers` primitive. If any approved candidate fails, no downstream PDBQT preparation is allowed.

## Gate B: 105-SDF audit

```powershell
python scripts/audit_partial35_conformers.py `
  --contract specs/partial35_exploratory_package_v05.json `
  --protocol specs/competition_conformer_protocol_v1.json `
  --data-root <DATA_ROOT> `
  --package-directory <DATA_ROOT>/standardized_ligands/partial_packages/competition_v1_partial35_mmff_qc_pass
```

The gate requires the exact 35 candidates in canonical order, 105 SDF files, valid raw-byte hashes, frozen protocol/chemistry provenance, valid convergence/selection metadata, and the exact excluded set.

## Ligand preparation and Gate C

```powershell
python scripts/prepare_partial35_ligands.py `
  --partial-package <DATA_ROOT>/standardized_ligands/partial_packages/competition_v1_partial35_mmff_qc_pass `
  --partial-contract specs/partial35_exploratory_package_v05.json `
  --generation-protocol specs/competition_conformer_protocol_v1.json `
  --candidate-manifest specs/top40_candidates_v05.json `
  --screening-protocol specs/screening_protocol_v05.json `
  --data-root <DATA_ROOT>
```

This runs Meeko 0.8.0 once for each audited SDF using the frozen backbone-rigid preparation. It does not regenerate peptide chemistry or coordinates. The derived 120-slot inventory contains 105 `approved_for_exploratory_screening` slots and 15 `conformer_generation_qc_fail_not_docked` slots.

```powershell
python scripts/run_batch_v05.py `
  --manifest specs/top40_candidates_v05.json `
```

The dry-run must report 35 candidates, 105 conformers, and zero Vina processes. Only after it passes may the identical command use `--execute` instead of `--dry-run`. V0.5-B copies the already-audited, hash-locked PDBQT into each immutable attempt and reruns the normal pre-docking audit; it does not prepare a replacement PDBQT.

If interrupted, use the exact same command with `--resume`. Never restart the batch at a new output root merely to bypass a valid interrupted attempt set.
