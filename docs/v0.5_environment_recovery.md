# V0.5 Windows environment reconstruction

The project virtual environment is disposable. Reproducibility comes from a
compatible base interpreter, the version-controlled dependency lock, the
environment preflight, and regression against approved A4/B3 data. The PyMOL
environment remains separate from the chemistry/project environment.

## Chemistry/project environment

1. Install a compatible Windows CPython 3.12.x interpreter. Do not use Conda
   base Python 3.14.
2. Create a fresh project virtual environment with that interpreter.
3. Activate it and install exactly `requirements-v05-lock.txt`.
4. Run a V0.5-A dry-run for A4 or B3. This verifies Python 3.12, every locked
   installed distribution, receptor and chemistry contracts, Vina identity,
   and approved ligand inputs without starting Vina.
5. Run the complete automated suite in the chemistry/project environment,
   excluding the PyMOL-only test module.
6. Run the PyMOL-only regression in the separately maintained PyMOL Conda
   environment.
7. Reproduce the approved no-docking A4/B3 analysis regressions before resuming
   any formal screening work.

Example reconstruction commands, using an explicitly selected Python 3.12:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --requirement requirements-v05-lock.txt
```

The lock pins the complete verified runtime distribution set, including RDKit
2026.3.6, Meeko 0.8.0, ProDy 2.6.1, and their installed scientific/runtime
dependencies. `pyproject.toml` records the Python minor constraint and direct
project dependencies without turning the repository into a packaged
application.

## PyMOL environment

PyMOL is not a V0.5 production-runner dependency. Continue to use the separate
Conda environment for headless visualization and PyMOL regression. Do not add
the chemistry virtual environment's `site-packages` to the PyMOL interpreter,
and do not merge the two environments merely because both can import Python
modules.

An import-only check is insufficient. Environment acceptance requires exact
version checks plus the approved scientific-output regressions described above.
The `.venv` directory itself remains excluded from Git.
